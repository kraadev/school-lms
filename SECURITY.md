# Kebijakan keamanan

School Space menangani akun dan data kegiatan belajar. Jangan mengirimkan data pribadi, unggahan pengguna, kredensial, token, atau private key saat melaporkan masalah.

## Melaporkan kerentanan

Jangan membuat issue atau pull request publik untuk kerentanan yang belum diperbaiki. Gunakan **Private vulnerability reporting** pada tab **Security** repository GitHub jika fitur tersebut diaktifkan. Jika belum tersedia, minta kanal pelaporan privat dari maintainer tanpa mempublikasikan detail teknis.

Sertakan versi/commit yang terdampak, dampak, prasyarat, dan langkah reproduksi yang aman. Beri waktu kepada maintainer untuk menilai dan memperbaiki masalah sebelum pengungkapan publik.

Maintainer: aktifkan Private vulnerability reporting di pengaturan repository sebelum menerima publikasi dan laporan eksternal.
